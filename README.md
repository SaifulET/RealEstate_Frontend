## Project Description

The frontend is a Next.js 16 application built for real estate teams to manage projects, visualize floor plans, and generate polished project presentations. It includes authentication, dashboard editing, folder-based project organization, multilingual support (`en` and `ar`), theme switching, and export-ready floor planning views for PDF and image output.

### Frontend Highlights

- Built with Next.js App Router, React 19, TypeScript, Tailwind CSS, and Zustand.
- Supports login, password recovery, OTP verification, and profile/company management.
- Provides dashboards for project browsing, floor/unit editing, model management, and folder-based organization.
- Includes export features for printable layouts and downloadable project images.
- Uses Axios interceptors for token handling, refresh flow, locale headers, and cookie-based auth support.
